# DOSwriter Feature Briefs

## 1. Dynamic Font Control: Hotkeys & Unicode Support
DOSwriter provides instant typographic control through dedicated hardware hotkeys, allowing writers to increase or decrease font size on the fly without breaking their creative flow. The engine supports a wide array of high-quality internal and external Unicode TrueType/OpenType fonts, ensuring crisp legibility and complete character support across multiple languages. Whether using a distraction-free Monospace or a sophisticated Serif, the app intelligently maintains layout consistency across all your devices.

## 2. Atmospheric Comfort: Smart Color Themes
Designed for use in any environment, DOSwriter features a robust theme engine optimized for ambient lighting comfort. Users can transition between high-contrast light modes for outdoor use and muted, eye-strain-reducing dark modes for late-night sessions. For E-Ink users, specialized monochrome themes eliminate ghosting and maximize battery life, while integrated Day/Night scheduling automatically shifts the workspace colors based on the local time.

## 3. The Working Text View: The DOSwriter Buffer
At the heart of the application is the Buffer—a high-performance, single-instance text view engineered for speed and stability. Unlike standard mobile text fields, the DOSwriter buffer is built to handle massive manuscripts without lag, providing a stable "working stage" for your content. It manages everything from character limits and dirty-state tracking to individual typographic overrides, ensuring that your text is always safe and exactly where you left it.

## 4. Multi-Buffer Workspace & Layout Overview
Efficiency is maximized through a multi-buffer architecture that supports up to 8 active writing slots plus a dedicated scratchpad. Writers can instantly swap between different chapters, research notes, or To-Do lists using `ALT+1-8` or the visual Buffer Layout View. The Layout View provides a bird's-eye perspective of the entire workspace, featuring persistent thumbnails and smart labels that visualize the current state of every open document.

## 5. Small Screen Navigation: Bookmarks & Text Collapse
Navigating large files on mobile devices is effortless thanks to intelligent Bookmarks and Text Collapse (Folding). Bookmarks allow for instant jumps between key plot points, marked by high-contrast `[BK]` icons and dimmed context previews. Complementing this, Text Collapse lets users hide completed sections or research notes behind a simple `[+]` icon, decluttering the viewport and allowing the writer to focus purely on the active scene.

## 6. Visualizing Structure: Filmstrip & Manuscript Layouts
To assist with high-level document organization, DOSwriter offers specialized structural views. The Filmstrip view provides a scrollable, horizontal preview of document segments, ideal for checking the rhythm and flow of a manuscript. For a more comprehensive look, the Manuscript Layout view tiles the document into a grid, allowing writers to visually analyze their progress and structure across multiple virtual "pages" simultaneously.

## 7. Project Navigation: Outline Manager & File Preview
The Outline Manager acts as a hierarchical project hub, enabling writers to organize complex manuscripts into custom containers, chapters, and nested folders. By linking individual external files into a cohesive project tree, it facilitates a high-level view of the document structure while providing instant, keyboard-driven navigation between sections. Complementing this, File Preview allows for rapid content verification during the selection process, ensuring the correct draft or research note is identified before loading, thus maintaining a continuous and focused creative state.

## 8. Markdown Workflow: Professional Editing & Live Preview
DOSwriter supports a robust Markdown editing environment, perfect for writers who require structured formatting without leaving the keyboard. The editor highlights syntax in real-time, while the Live Preview mode (`ALT+R`) renders headers, tables, lists, and images in a clean, professional layout. This dual-mode approach allows for high-speed drafting in plain text with the confidence that the final output will be perfectly formatted for publishing or distribution.

## 9. Task Management: Built-In To-Do Workspace
Writers can seamlessly toggle between their manuscripts and their task lists using the specialized To-Do Workspace (`ALT+W`). This independent environment provides 8 dedicated buffers pre-populated with templates for daily goals, plot tracking, and research milestones. The To-Do mode maintains its own independent state, allowing you to manage your project's logistics without cluttering your primary creative buffers.

## 10. Command Mastery: Intuitive Shortcuts & Integrated Help
Reflecting its keyboard-centric philosophy, DOSwriter minimizes menu-diving through a comprehensive system of intuitive `CTRL` and `ALT` command chords. For users needing a quick reference, the Integrated Help system provides searchable, Markdown-based documentation that can be summoned instantly with `CTRL+H`. This ensures that every tool—from advanced search and replace to hardware-specific settings—is always accessible at your fingertips.

## 11. Custom Accessibility: The DOSwriter Virtual Keyboard
For devices without physical hardware, the DOSwriter Virtual Keyboard offers a tailored input experience optimized for retro writing. Beyond standard alpha-numeric keys, it includes specialized layouts for navigation and secondary symbols, along with a unique **CTRL Lock** feature for modifier-heavy operations. This design ensures that the app remains a powerful, distraction-free writing tool on any touch-screen device.
